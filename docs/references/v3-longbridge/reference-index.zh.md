## 视觉准则

- 将截图作为深色胶囊导航轨道、四项灰色基础层和白色活动视觉副本的首要视觉目标。
- 移动镜片是可以越出轨道的圆形厚玻璃表面；它局部放大并折射导航内容，而不是扁平的
  选中标签背景。
- 在加入装饰性色彩效果前，优先匹配中性的灰白边缘、上下椭圆焦散、内侧暗环和依赖背景
  的局部折射。
- 当 V3 改动可能影响轨道后方复杂内容上的对比度或可读性时，必须审阅图表上下文截图。

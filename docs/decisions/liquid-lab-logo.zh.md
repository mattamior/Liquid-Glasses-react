# Liquid Lab 标志决策记录

实现提交：[`465c7b2`](../../../../commit/465c7b2)

## 范围

为 Liquid Lab 定义一套原创标志：它应在小尺寸下保持清晰，适配亮色和暗色
界面，并表达项目对折射、高光与分层玻璃材质的研究。该标志是独立视觉身份，
不复制 X 标志、Cloudflare 标志或 Apple 图形资产。

## 决策

当前采用圆角、实心的 `L` 字母组合。它在小尺寸下仍可识别，同时以材质表现一
个厚玻璃转角：

- 暗色模式使用青绿 `#4bd4d2`、冰蓝 `#639dea` 到柔和紫色 `#9674cc` 的冷调
  光谱。
- 亮色模式使用对应的低饱和版本：`#a8e1df`、`#a9bce0`、`#c5b4d5`。
- 半透明内层、克制的白色边缘高光和相对的深色折射线共同表现玻璃厚度。
- 高光与阴影都从内层表面的同一套四像素内缩几何派生，而不是独立装饰轮廓；
  这样能防止圆角和竖边再次错位。

## 决策过程

1. 首先尝试纯黑白的简约 `L`，以接近 X 的克制感和小尺寸识别度为目标；但它
   无法表达本项目的材质研究。
2. 接着测试了黑白的细线中空版本。嵌套轮廓彼此竞争，并在小尺寸下变得含混，
   因此放弃。
3. 曾尝试高对比的暖黄、橙、红实心方案。它与 Cloudflare 的色彩联想过强，
   无法形成 Liquid Lab 自己的视觉身份，因此放弃。
4. 选定当前青绿、冰蓝、淡紫的冷调玻璃材质：暗色模式保留更明显的光学色彩，
   亮色模式降低饱和度。
5. 放大审查发现内高光的路径未可靠贴合内层表面，随后按内层边界重绘；右下阴影
   同样按对应边界重绘。

## 后续边界

当前标志是已接受的基线，并不代表停止探索。任何后续方案必须在预览页中与该
基线并列比较，检查 24px 与 32px，并在明确确认后才能替换正式资产。一个值得
探索的方向是在 `L` 转角使用一段连续的折射窗，而不是继续增加嵌套轮廓。

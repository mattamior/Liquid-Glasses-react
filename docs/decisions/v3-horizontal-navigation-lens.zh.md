# V3 横向导航透镜决策记录

## 范围与决策

将 V3 作为独立的横向导航透镜研究引入。导航使用内嵌选中滑块，而不是让选中面
延伸到外壳边缘。普通标签激活保留大镜片横向移动的转场；直接拖拽会吸附到最近
格位并改变选中标签，不重复播放该转场。

## 已交付结果与改动区域

- [`/v3`](../../app/v3/page.tsx) 提供四列横向导航，包含导航级选中滑块，以及
  裁切后的白色视觉副本，用于显示当前激活标签或拖拽预览标签；基础导航内容
  保持灰色。
- [`app/v3/v3.css`](../../app/v3/v3.css) 为桌面导航设置 `10px` 内侧边距，并在
  移动端使用更窄内边距，使选中滑块填满内层网格格位且保留外壳边距。
- Pointer Events 支持从当前激活标签开始的主鼠标、触控和触控笔输入，采用指针
  捕获、`5px` 拖拽阈值、边界钳制、取消回退，以及 `260ms` 吸附到最近标签。
- Edge optics 使用与镜片同尺寸的本地视口处理 SVG 位移滤镜。导航世界副本在
  大镜片转场中仍可见，不再被透明裁切。

## 验证证据

- `npm test` 通过：5/5 个测试。

  内容为灰色，滑块内内容为白色。
- 本地交互检查确认鼠标拖拽、拖拽阈值、取消回退和后续普通点击激活正确；同时

- 约 `340ms` 的转场取样中，原有 `aria-current` 在大镜片经过中间标签时仍被保留；
  Edge optics 显示被折射的图标与文字内容，滤镜区域没有空白。

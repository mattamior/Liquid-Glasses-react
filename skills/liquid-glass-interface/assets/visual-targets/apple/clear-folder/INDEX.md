# Apple Clear folder visual targets

Review-only stills. Not runtime assets and not cross-browser pixel truth.

| File | Use |
| --- | --- |
| `ambient-surface.png` | Light home-screen environment the glass must sit over. |
| `compact-glass-container.png` | Compact Clear folder: hairline rim, wallpaper color through the pane. |
| `full-glass-container.png` | Full Clear folder/panel. |
| `night-ambient-surface.png` | Dark environment. |
| `night-compact-glass-container.png` | Dark compact pane. |
| `night-full-glass-container.png` | Dark full pane. |

Fail the visual gate if the result reads as a painted frosted card, has a closed cyan/purple ring, distorts foreground labels, or places glass in a content-card grid.
